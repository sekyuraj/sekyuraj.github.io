BIOS tuning steps

Gigabyte B650 Gaming X AX V2 (F38) · Ryzen 9 9950X · Corsair DDR5-6000 CL36 2×16 GB · RX 9070

Download this page

Already done: EXPO I, PBO Advanced, PBO Limits Motherboard, +100 MHz, Curve Optimizer All Cores −10. Do one block, reboot, test, then the next. Press F2 in the BIOS for Advanced Mode, F10 saves.

1. RAM

Tweaker tab:

Tweaker → Advanced Memory Settings → Memory Subtimings. Don't touch the first four (36-36-36-76).

settingvalue
tRFC1500
tREFI65535
tRRDS8
tRRDL8
tFAW32
tWTRS4
tWTRL16
tWR48
tRTP12

Test in Linux, must finish with no fail:

stress-ng --vm 16 --vm-bytes 85% --verify -t 30m
Fails: set FCLK back to Auto first. Still fails: subtimings back to Auto. Won't boot at all: wait 5 min, then power off/on 3 times (safe mode), or clear CMOS.

2. CPU: Curve Optimizer per core

Tweaker → Precision Boost Overdrive → Curve Optimizer → Per Core. Sign Negative on every core:

coresmagnitude
Core 0, 1, 2, 5 (fastest)10
Core 3, 4, 6, 720
Core 8 to 1525
stress-ng --cpu 32 --cpu-method all --verify -t 20m
Random reboot or freeze (often when idle): lower the 20 and 25 groups by 5.

After a stable day:

3. GPU (in Linux)

sudo nano /etc/default/grub

Add this inside the quotes of GRUB_CMDLINE_LINUX_DEFAULT:

 amdgpu.ppfeaturemask=0xfff7ffff
sudo grub-mkconfig -o /boot/grub/grub.cfg

Leave alone

CPU Vcore / ratio, Global C-state Control, EXPO II, memory above 6000, Resizable BAR, Smart Fan (only raise curves, never lower).
